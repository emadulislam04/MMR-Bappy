## 🚀 Run & Build Locally

### Prerequisites
- Node.js (v18+)
- npm

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

To preview the production bundle locally:
```bash
npm run preview
```
